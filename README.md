# StarLift: локальный запуск на Mac

Бэкенд, фронтенд, Postgres, MinIO, Redis и аудиоворкер запускаются одной командой:

```bash
./tools/audio-analysis/local.sh up
```

Откройте http://localhost:5174. Фронтенд обращается к локальному бэкенду.
Демо-данные загружаются в отдельную локальную базу; это не данные общего стенда.

Нужны запущенный Docker Desktop, Python 3, FFmpeg и установленные модели
Whisper/Silero по инструкции в `tools/audio-analysis/README.md`.
Рядом с этим репозиторием должен лежать `starlift-frontend` с поддержкой
аргумента сборки `VITE_API_BASE_URL`. Другой путь можно задать через
`STARLIFT_FRONTEND_DIR` (абсолютный путь).

`compose.local.yaml` поднимает сервисы с отдельными томами и портами:
фронт 5174, API 18081, Postgres 15439, MinIO 19090. Порты доступны только
на этом компьютере. Настройки production Compose не меняются.
На Mac воркер запускается через launchd нативно, чтобы использовать Metal.
Его секрет и журнал хранятся в `~/.local/share/speakers-audio-analysis/local`.

```bash
./tools/audio-analysis/local.sh status
./tools/audio-analysis/local.sh logs
./tools/audio-analysis/local.sh down
```

Остановка сохраняет базу и загруженные записи. Повторный `up` пересобирает
изменившийся код контейнеров и сохраняет работающий воркер. Если изменён
сам Python-воркер, перезапустите его через `down` и `up`.
Для анализа речи откройте раздел спикера «Медиа».
Смысловой разбор через GigaChat и внешние агенты в этом локальном сценарии
не настроены; аудио обрабатывается локальным воркером.
